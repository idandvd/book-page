# דף ההקלטה לספר

## העלאה ל-GitHub Pages (פעם אחת)
1. ב-github.com: New repository, שם: `book`, ציבורי (Public).
2. Add file ← Upload files: להעלות את `index.html` ו-`recording.mp3`.
3. Settings ← Pages ← Source: Deploy from a branch, Branch: `main`, תיקייה `/ (root)` ← Save.
4. אחרי דקה-שתיים הדף זמין ב: `https://USERNAME.github.io/book/`

## סטטיסטיקה (אופציונלי)
1. לפתוח חשבון חינמי ב-goatcounter.com.
2. ב-`index.html` להחליף את `YOURNAME` בשם שבחרת, ולהעלות מחדש.
3. בלוח הבקרה של GoatCounter יופיעו כניסות, וגם האירועים `play`, `listened-to-end`, `download`.

## דומיין משלך (מומלץ לפני ההדפסה)
Settings ← Pages ← Custom domain. כך ה-QR יפנה לדומיין שלך, ואפשר יהיה להחליף אירוח בעתיד בלי לשנות את הספר.

## בשנה הבאה
לשנות את שם `next-year-redirect.html` ל-`index.html`, להכניס את כתובת היעד ולהעלות.
